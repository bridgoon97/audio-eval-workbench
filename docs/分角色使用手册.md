# 听鉴 · 分角色使用手册

适用版本：0.7.0

## 管理员

你负责服务主机、账号和数据维护，可以管理全部任务。创建评测的操作见“组织者”指南，听评操作见“评测者”指南。

### 首次启动与局域网部署

只需在一台主机运行服务，同事通过浏览器使用。

1. 完整解压 Windows 包，保留 audio-eval.exe 旁的 _internal 目录。第一次启动时，浏览器中填写程序窗口显示的初始化密钥，创建管理员账号；密码至少 10 个字符。
2. 本机试用可双击程序。需要同事访问时，在程序目录的 PowerShell 中运行：.\audio-eval.exe --lan --data D:\音频评测数据。数据目录选择主机上的固定目录。
3. 使用 ipconfig 确认主机当前 IPv4，同事访问 http://主机IP:8765。若未指定 --data，默认数据保存在运行账号的 .audio-eval-workbench 目录。
4. 按公司网络策略允许需要的同事访问 TCP 8765；主机保持开机，避免睡眠。若权限由 IT 管理，请让 IT 配置规则，不通过关闭防火墙解决。
5. 第一次请让一位同事登录、打开分配的合成演示任务、播放并保存一条标注，再核对主机端能否看到。

- 默认 HTTP 不加密传输，仅用于获准的可信局域网试用。需要 HTTPS 时由组织配置反向代理，以 --public-origin https://实际内部域名 指定外部源；程序不自动配置证书。
- 不用把运行数据库共享给同事写入。源音频文件夹共享与网页服务是两回事。

### 账号开通与角色分工

按同事实际工作分配权限；已有账号可以直接调整角色。

1. 打开左侧“团队成员”，填写账号并选择角色，初始密码已自动生成，再点击“创建账号”。也可以让同事在登录页凭邀请凭证自助申请，由你在“加入与邀请”中审批。
2. 只需试听、写标注和提交判断的同事选择“评测者”；需要创建任务、上传音频、发布或整理结果的同事选择“组织者”。
3. 已有同事需要上传时，在成员列表中把其角色改成“组织者”，其在线网页会在约 5 秒内同步；无需重新创建账号。请通过团队认可的方式单独交付账号密码。
4. 组织者可管理自己创建的任务和邀请已有账号参与，不能修改其他人的任务、管理账号或下载全站备份。管理员可以管理全站任务。
5. 将组织者降回评测者后，已有会话立即失去创建与管理权限，在线网页会自动更新菜单。其任务仍保留，由管理员管理或再次授权后继续。

- 成员列表入口不能修改管理员角色；管理员账号不能被停用。成员行支持重置密码（同时撤销其全部登录会话与设备免密凭证）与停用/启用账号。
- 获得共享数据文件夹读写权限，不会自动成为软件组织者。

### 自动生成密码与凭证交付

使用账号加随机密码登录，无需为每位同事构思密码；不是免密登录链接或 API Token。

1. 打开“团队成员”，初始密码已自动生成；也可以点击“生成随机密码”换一个，或自行填写至少 10 个字符。默认随机密码为 24 个字符。
2. 填写账号并选择角色。先核对“同事登录地址”：如果自己通过 localhost 或 127.0.0.1 打开软件，请改成同事实际使用的局域网地址。这只修改凭证卡，不改变服务配置。
3. 点击“创建账号”，成功后出现本次登录凭证卡，包含地址、账号和密码。点击“复制登录凭证”，单独交给对应同事；浏览器限制复制时会选择文本，按 Ctrl+C 或 ⌘C 手动复制。
4. 关闭成员窗口后不再显示明文凭证；本版不提供原密码查询。服务端保存加盐口令哈希，不在浏览器本地存储中保存生成的密码。
5. 同事遗失密码时，在成员行点击“重置密码”，预览新随机密码，再输入完整账号名确认。确认后旧密码失效，该账号所有登录会话撤销，角色、任务和评分保留。将新的凭证卡单独交给本人。

- 此重置入口只处理同事账号，不修改管理员密码；普通组织者和评测者不能重置其他人。
- 重置必须由管理员确认后才生效，不会因为打开预览就更改密码。

### 邀请凭证与加入审批

有需要的同事凭一次性邀请凭证自助申请；你批准并分配任务后，对方才能进入。

1. 打开左侧“加入与邀请”，切换到“邀请凭证”，填写用途或备注，选择团队邀请或绑定单个任务的邀请，设置有效期（天）和最大使用次数，点击“生成邀请凭证”。
2. 明文凭证只在生成时显示一次：点击“复制邀请凭证”后通过可信渠道单独发给申请人；关闭窗口后无法再次查看。
3. 任务邀请只能申请该任务；团队邀请由你在批准时勾选正在评测中的任务。提交申请只校验资格，使用次数在批准时才消耗，拒绝不消耗。
4. 在“加入申请”页查看待审批列表：申请编号、显示名称、工号/邮箱、提交时间、来源 IP、简化设备信息与邀请用途。点击“批准…”设置账号名称（默认显示名称，可改）、角色（评测者/组织者）和任务，确认后立即生效。
5. 重复批准同一决策是安全的；改变决策会被拒绝。拒绝请点“拒绝”，同样立即生效。
6. 批准创建的账号初始没有可用密码：对方通过批准浏览器的设备凭证免密登录；必要时可在成员行重置密码。

- 凭证明文只在生成时显示一次；服务端只保存带独立盐的哈希，列表和备份都无法恢复明文。
- 邀请被停用、过期或次数用尽后，等待中的申请会在下次查询时自动过期，终态不能被普通重试反转。
- 申请页面不暴露邀请状态细节，也不会透露是否存在同名账号；批准重名名称时会要求修改账号名称。

### 登录设备与撤销

批准后的浏览器获得长期设备凭证，可以免密登录；你可以随时撤销。

1. 打开“团队成员”，点击成员行的“登录设备”：这里显示简化后的浏览器与系统、首次和最近访问时间及 IP、绝对过期时间。
2. 撤销单个设备，或一键撤销该同事的全部设备；撤销在下一次请求立即生效，密码登录不受影响。
3. 同事更换浏览器或设备疑似失窃时：重置密码会一并撤销其全部会话与设备免密凭证；也可只撤销设备并生成一次性恢复凭证，让本人自行设置新密码。

- IP 只用于审计与风险提示，绝不是登录凭证；同一设备令牌更换 IP 后仍然有效，并会更新最近访问 IP。
- 设备令牌只保存哈希，数据库、列表和备份中都拿不到明文。
- 批准账号没有可用密码；撤销设备后如需在别的浏览器登录，必须由管理员重置密码。

### 备份、升级与恢复

数据保存在服务主机；程序文件与数据目录分开维护。

1. 在任务首页点击“下载完整备份（含音频）”。ZIP 包含任务、音频、账号口令哈希，也包含回收站任务；请按其中数据的最高权限妥善保管。
2. 升级前先备份并退出旧服务。将新版本完整解压到新的程序目录，使用原来的 --data 目录和 --lan 参数启动，让同事刷新网页。
3. 从 0.2 升级时自动创建回收站表并保留已有任务。旧版本不认识回收站权限，升级后不要让旧版打开同一数据目录。
4. 需要恢复时先停止服务，把完整备份解压到一个新的数据目录，用 --data 指向该目录启动。不要覆盖正在运行的数据库。
5. 恢复会清除旧登录会话，需要重新登录。抽查账号、任务、播放、评论和评分；若回退软件版本，使用升级前备份的独立副本。

- 备份目前在内存中生成，适合短音频、小团队；没有自动定时备份。回收站只是可恢复删除，不释放磁盘空间。

### 恢复凭证与账号停用

浏览器丢失或账号需要临时冻结时，管理员有两件工具：一次性恢复凭证与停用开关。

1. 打开“团队成员”，点击成员行的“恢复凭证”，填写用途并选择有效期（1–72 小时），生成后明文只显示一次，通过可信渠道单独发给本人。
2. 本人打开登录页的“凭恢复凭证设置新密码”，输入凭证与新密码；成功后直接登录，旧密码与旧设备全部作废。
3. 点击成员行的“停用账号”可立即冻结同事：所有会话与设备下一请求即失效，密码登录与恢复领取同时被拒；历史评论、评分与任务归属完整保留。
4. “启用账号”只恢复登录资格，不恢复任何旧会话或设备；同事需要重新登录，忘记密码时重新生成恢复凭证即可。
5. 生成恢复凭证前账号必须处于启用状态；已使用或过期的凭证在成员的凭证列表中可见（仅用途与时间，无明文）。

- 管理员账号不能被停用，这保证站点永远至少有一名可用管理员；停用他人前请确认不是对方正在进行的评审关键角色。
- 恢复凭证只保存加盐哈希，明文丢失只能重新生成；备份包含凭证哈希与停用状态，但不含明文。

## 组织者

你可以创建和管理自己的任务，包括上传、发布、关闭、导出和回收站恢复；参与别人任务时按评测者流程操作。

### 准备一组公平的比较

以“同一片段的 AIBF v1、AIBF v2、竞品输出”为例，先在导入前确认素材关系。

1. 三个版本应对应同一输入、同一时间范围。将输入切成 0.01–120 秒的片段，准备 16 kHz 的 WAV，每个文件不超过 32 MB。
2. 软件支持单通道和 4 通道；默认 4 通道映射为 FB / FF / TT / VPU。其他来源的 4 通道文件必须先核对通道顺序，不能套用该映射猜测。
3. 每道题需要 2–6 个候选。保留 commit、模型 SHA 或可追溯版本号，并记录已做过的时延和增益处理。软件不运行算法模型，导入的是已有输出。
4. 竞品算法使用相同输入；若是不同设备分别录音，创建时选择“竞品整机”。AIBF、VPU 支路和级联链路可分别建立任务，避免混淆比较目的。
5. 选择真实的数据来源级别：PUBLIC reproducible 表示公开可复现；DECLASSIFIED real-device 表示已获准脱密的真机素材；PRIVATE local verification 表示受限本机验证。标记不等于授予公开传播权限。


### 新建任务与工作模式

点击任务首页“新建评测”，填写清楚这轮比较想回答的问题。

1. 任务名称建议写成“AIBF v1 与 v2 · 车内场景 · 第一轮”。选择对应的比较场景：算法版本、VPU 支路、级联链路、竞品算法或竞品整机。
2. 选择“开发诊断”可显示名称、版本、波形和频谱，适合定位问题与共同讨论；选择“隐藏版本”可在发布后隐藏版本身份，适合独立偏好收集。
3. 点击“创建任务”后，任务处于“准备中”，普通参与者还看不到它。先导入并检查素材，再发布。
4. 名称、比较类型或模式写错时，准备阶段点击“编辑任务”修正；打开片段后点击“编辑片段”，可修正片段名称、场景和来源标记。发布后这些信息与音频一同冻结。
5. 开发诊断的评论会对成员公开。若希望同事不受他人意见影响，应在创建时选择隐藏版本模式。


### 对齐与响度（草稿，可选）

发布前可为每个片段选参考候选，做恒定整数采样对齐与活动段 RMS 匹配；原始 WAV 永不修改。

1. 打开草稿片段，点击“对齐与响度”，选择参考候选并点击“开始分析”。参考候选保持 0 samples / 0 dB，其他候选逐一给出延迟与增益诊断。
2. 延迟使用三窗口归一化互相关，搜索范围 ±1600 samples（±100 ms）。正 lag 表示候选相对参考晚到 N samples，应用时前移 N samples（端部补零/裁切，长度不变）。
3. 自动可应用需同时满足：聚合相关峰 ≥0.55、峰旁瓣比 ≥1.5（排除主峰 ±8 samples）、三窗口 lag 极差 ≤4、不触搜索边界。强周期纯音、低相关噪声、漂移、全静音都会被拒绝并给出拒绝码。
4. 响度是“活动段 RMS 匹配”：以参考轨活动掩码（帧 RMS 90 分位 ×0.25，≥1e-4 满刻度）在同一对齐位置比较。活动时长与覆盖按活动帧并集内非静音样本数计（帧重叠不重复计数）：共同有效活动需 ≥0.5 秒且覆盖 ≥10%，增益 ≤±12 dB，应用后预测峰值 ≤−1 dBFS。
5. 它不是 LUFS/ITU BS.1770 响度校准，也不是听感等响；物理传感器或不同内容不一定能可靠相关。只有对应判据通过才能勾选，低置信建议请保持原始。
6. 应用前核对处理摘要（顺序固定：先整数采样对齐，再固定增益）。生成派生试听资产后可“恢复原始处理”；片段已有评论或评分后不能再替换试听资产。
7. 发布确认会显示各片段是否存在混合处理口径与被拒绝的建议；发布后播放处理冻结，结果导出包含实际处理证据。

- 原始 WAV 与其 SHA256 永不改变；派生资产带完整 provenance（前后 SHA、lag、增益、活动门限/覆盖、峰值、时间），随完整备份一起保存。
- 建议只是减少反复手动校对的工程辅助，不构成算法优劣判断。

### 单个上传与共享目录

共享文件夹的读取权限让你能选到源文件，组织者角色让你能在软件中建题。

1. 少量素材：点击“添加片段”，填写名称、场景和数据来源；接着填写候选版本名称、版本证据、读取通道并选择 WAV。
2. 第一个候选导入后，点击“导入这个片段的另一个版本”，继续添加相同时间段的其他输出。每个片段至少两个版本才可发布。
3. 源文件在共享目录时，在 Windows 文件/目录选择器中进入有权读取的共享文件夹或映射的网络驱动器，再选择文件上传。只需读取源音频的权限。
4. 浏览器把文件上传到服务主机，软件保存独立试听副本，不修改源文件。后来修改共享文件不会替换已导入音频；网页不能直接依据你输入的主机路径扫描目录。
5. 导入后核对波形、RMS、峰值和近满幅采样提示，再实际试听。候选长度一致只是一项校验，仍须外部确认时间同步。


### 按版本目录批量导入

例如选择 AIBF-v1/、AIBF-v2/、竞品/ 三个目录，让它们内部都有“车内/001.wav”。

1. 点击“批量导入”，为每个版本填写名称、版本证据和读取通道，分别选择版本目录；用“增加版本”扩展到最多六个。
2. 软件忽略各版本根目录名，按内部完整相对路径匹配，区分大小写和子目录。车内/001.wav 与室内/001.wav 是不同题目。
3. 查看“匹配预览”：缺失、重名、文件过大和任务内已有的片段会标明并跳过。选目录时仅在浏览器预览，点击“确认匹配并导入”后才上传。
4. 每次上传一个片段的全部候选，校验全部成功才建题。中途失败会暂停，不留下半道题；已成功的其他片段继续保留。
5. 点击暂停会等待当前片段完成。本窗口中可继续或重试而不重复建题；需要改文件时关闭并重新打开导入窗口。刷新后重新选目录会跳过已有片段。


### 发布、分配与统一揭晓

发布会冻结输入与比较协议；进行中仍可调整尚未贡献评测记录的参与人员。

1. 确认每个片段有 2–6 个候选、时间对齐及增益处理已核对。草稿候选右侧“管理”可更名或更新版本证据，也可确认删除；有相关标注时保留音频依据。
2. 点击“发布评测”，勾选受邀同事与对齐及增益确认，点击“发布并锁定任务”。默认不包含你自己；要在收集期提交偏好，请勾选“我也参与评测”。缺账号时请管理员先创建。
3. 发布后不能替换音频、添加版本或修改名称与模式。需要新增同事时点击“受邀评测者”勾选已有账号；在线同事约 5 秒内会看到任务。
4. 受邀名单可在任务进行中调整。尚未评论或评分的人可以移出；已经产生评论或判断的人会保留。任务创建者自动拥有访问权限，是否受邀由勾选决定，已提交评论或判断后不能取消受邀。关闭任务后名单冻结。
5. 隐藏版本评测进行中，评测界面不显示真实名称和其他人的标注，也不能查看汇总。负责人可在关闭前点击“评测进度”确认受邀同事的完成数量与状态，这里不含任何偏好内容。
6. 准备结束收集时点击“关闭并揭晓”，确认后停止接收新评分并统一显示身份与意见。这是最终关闭，本版没有重新开放收集入口。
7. 点击“查看结果”查看受邀评测进度、逐片段偏好与问题标签。可导出证据 JSON、结果 CSV（中文 Windows Excel 可直接打开）和复盘 Markdown；三种导出都包含任务信息、分母口径和稳定 ID。


### 结果复盘与导出

关闭并揭晓后，“查看结果”把参与进度、逐片段偏好和问题标签放在一起复盘。

1. 参与进度按受邀评测者统计三态：已完成＝已提交全部片段；进行中＝已提交部分片段；未开始＝尚未提交。名单来自评测分配；负责人自动拥有访问权限，但不自动受邀。只有受邀评测者的评分计入结果，负责人若要参与，在发布或受邀名单中勾选自己。评论不算提交。
2. 逐片段偏好显示每个候选和“无明显差异”的票数与百分比。百分比以该片段的有效提交人数为分母（每人每片段至多一票）；不同片段分母可能不同，缺失判断不计入。
3. 标注“存在分歧”的片段表示同一片段出现了两种及以上不同偏好。点击“回到此片段试听与标注”可回到该片段的试听区和评论楼层，结合具体听感讨论；分歧提示只是定位工具，不是结论。
4. 问题标签按标签统计根评论数量并列出涉及片段；回复楼层不计入。点击片段名可直接定位到对应片段。
5. 三种导出各有用途：证据 JSON 便于程序读取和留档；结果 CSV 供中文 Windows Excel 直接打开核对；复盘 Markdown 适合粘贴进周报或会议纪要。导出仅限任务管理者。

- 隐藏版本任务的汇总与导出只在关闭后生成；评测进行中任何人都拿不到，这是盲评边界的一部分。
- 票数更多只说明更多同事在这轮试听中更倾向该版本，不证明算法客观更优，也没有统计显著性。

### 删除、恢复与版本修订

删除适合移走误建或不再使用的任务，不是重新开启编辑的办法。

1. 打开自己有管理权限的任务，点击“删除任务”，输入完整任务名称，再确认移入回收站。草稿、正在评测和已揭晓任务都可移入。
2. 成员随后无法继续打开、播放或提交；原音频、评论、评分和成员名单保留。删除前确认该任务不再用于当前收集。
3. 回到任务首页，点击底部“回收站”，找到任务并点击“恢复任务”。普通组织者只看到自己能管理的任务，管理员能管理全站回收站。
4. 恢复后回到原有状态：正在评测的任务继续接受尚未提交的评分，已揭晓任务仍然关闭，已发布输入仍被冻结。需要重新比较新版本时另建任务。

- 组织者只能软删除与恢复；管理员可在回收站永久清除任务：预览将释放的片段/候选数量与字节，凭服务端一次性确认令牌执行，清除后不可恢复。
- 永久清除只删除该任务独占的记录与音频；被其他任务共享的文件不会误删。完整备份不再包含已清除任务及其独占资产。

### 修改自己的密码

点击左下角头像区的“账号与安全”，随时设置新密码。

1. 密码登录的同事需要先输入当前密码；免密设备登录的同事可直接设置新密码。
2. 保存后本浏览器保持登录；其他浏览器与设备会立即退出，需用新密码重新登录。
3. 忘记密码且无法登录时，请联系管理员生成一次性恢复凭证，在登录页“凭恢复凭证设置新密码”领取。

- 退出登录会撤销本浏览器的免密设备；换浏览器后无法免密进入是正常保护行为。
- IP 地址不是登录凭证；管理员也无法通过 IP 帮你恢复登录。

## 评测者

你的工作是独立试听、记录有时间定位的听感，并为每个片段提交一次偏好。无需安装软件或获得数据库目录权限。

### 登录并找到分配的任务

向管理员获取浏览器地址、账号和初始密码，向组织者确认评测目的和截止时间。

1. 在同一获准局域网中打开组织者提供的 http://主机IP:8765，登录账号。不要使用“localhost”或“127.0.0.1”访问同事主机，那会指向你自己的电脑。
2. 在任务首页打开分配给你的任务。准备中的任务不会显示；看不到时请组织者确认是否发布并选中了你的账号。
3. 先阅读任务名称、比较类型和片段场景，再从左侧逐个选择片段。尽量保持耳机、系统音量和试听环境一致。
4. “隐藏版本”任务在收集期间隐藏真实名称、波形、频谱和他人意见，这是正常行为。不要和同事对照字母猜版本，先独立完成判断。

- 评测者不能创建、上传、删除或发布任务，也不能导出任务证据或下载全站备份。需要负责一轮评测时请管理员授予组织者角色。

### 完成一段音频的听评

先听完整片段，再验证局部问题，最后提交偏好。

1. 试听各候选完整片段，再对不确定的时间区间循环切换。记录降噪与语音自然度之间的取舍，而不只用“好/差”概括。
2. 在“片段标注”中核对候选和起止时间，填写并保存证据。例如“3.20–3.65 秒尾音变薄；降噪更强，但语音细节损失”。
3. 切换到“偏好判断”，选更倾向的候选，或选“无明显差异”。可填写偏好原因，再点击“提交判断”。
4. 确认按钮显示“已提交”，然后继续下一个片段。选择候选但未点提交，不算完成；首页的已评数量只反映你自己的提交。
5. 提交后该片段的评分锁定，不能改选。需要修正时写补充评论，不要创建多个账号重复投票。


### 揭晓后的复盘

组织者关闭任务后，可以把抽象偏好还原成可重听的证据。

1. 重新打开任务，查看恢复显示的真实版本名称及其他人的标注；必要时点击记录区的刷新按钮。
2. 点击评论的时间按钮回到对应候选与片段，比较不同听众在同一位置听到了什么。可以回复和补充评论，但不再接收新评分。
3. 任务关闭后打开“查看结果”：受邀评测进度和逐片段计数一目了然；点击存在分歧的片段可回到试听区和评论楼层。几个人偏好某版本不代表所有场景都更好；不要把未完成或无明显差异误写成支持某版本。

- 结果与复盘视图在任务关闭后开放，导出文件仅任务管理者可以下载。

### 修改自己的密码

点击左下角头像区的“账号与安全”，随时设置新密码。

1. 密码登录的同事需要先输入当前密码；免密设备登录的同事可直接设置新密码。
2. 保存后本浏览器保持登录；其他浏览器与设备会立即退出，需用新密码重新登录。
3. 忘记密码且无法登录时，请联系管理员生成一次性恢复凭证，在登录页“凭恢复凭证设置新密码”领取。

- 退出登录会撤销本浏览器的免密设备；换浏览器后无法免密进入是正常保护行为。
- IP 地址不是登录凭证；管理员也无法通过 IP 帮你恢复登录。

## 通用操作与常见问题

### 同步试听与快捷键

先听完整片段，再循环问题区间；所有候选共用播放位置和监听音量。

1. 打开任务，从左侧选择一个音频片段，等待候选加载完成，点击底部播放按钮。建议使用同一副耳机，保持系统音量与音效设置一致。
2. 点击候选名称，或按 1–6 切换候选。播放头会继续前进，不需要从头播放。字母 A/B/C 只是当前用户的候选标记，不要假定另一位同事的 A 对应相同版本。
3. 开发诊断模式下可拖动波形选择区间；也可以直接填写“起点”“终点”（单位为秒）。隐藏版本评测时没有波形，使用起止时间框选片段。
4. 按 L 或点击底部循环按钮，在同一区间反复比较。空格播放/暂停，C 聚焦评论输入框；在输入框内或使用指南打开时，试听快捷键不会触发。
5. 底部音量滑块同时影响全部候选，不会单独提高某个版本的音量。开发诊断时可切换“频谱”，各候选共用色阶。

- 软件保留原始相对电平，不自动归一化、对齐或校正漂移。候选长度一样不代表内容已经同步。
- 切换采用短暂的 8 ms 增益过渡。判断瞬态或爆音时，请重播完整选区，不把切换瞬间当作算法缺陷。浏览器可能按声卡采样率重采样。

### 写下可复盘的标注

一条有用的标注应说明：哪个候选、哪段时间、听到了什么。

1. 先选中要评论的候选，再核对起点和终点。例如选择 3.20–3.65 秒，循环确认问题。
2. 在“片段标注”中选择问题标签，填写具体听感，例如“此处尾音变薄，背景噪声较低，但辅音细节损失”；点击“保存标注”。
3. 保存后在“片段记录”中确认出现该条记录。点击评论的时间按钮，可回到对应候选和区间；每条评论下方都可点击“回复”，后续对话按楼层聚合，并显示回复对象。
4. 开发诊断模式下，已保存标注对任务成员可见；隐藏版本模式在评测进行中只显示自己的标注，任务关闭后统一公开。需要查看其他人新写的内容时，点击记录区的刷新按钮。

- 未提交的评论文字仅暂存在当前浏览器，不是服务器备份；恢复草稿不会恢复完整候选、选区和回复关系，提交前重新核对。
- 评分提交后不能改选，也不能用重新登录覆盖原判断。需要纠正时在评论中补充说明；本版没有评论编辑/删除功能。

### 结果怎么解释

本版支持开发诊断与探索性偏好选择，不能直接当作正式 MUSHRA、MOS 或 ABX 测试。

1. 两个候选可用于 A/B 偏好比较；多个候选是在其中选择更倾向的一项，也可以选择“无明显差异”。没有标准 MUSHRA 的隐藏参考、锚点和连续评分协议。
2. 只有受邀评测者的评分计入结果；负责人若要参与，在发布或受邀名单中勾选自己。“查看结果”显示受邀评测者的三态完成进度和每个片段的原始偏好计数；百分比以该片段的有效提交人数为分母，每人每片段至多一票。没有提交的判断不计入；多次试听不会增加样本量，也没有计算显著性或置信区间。
3. 自研与竞品算法对比，应使用同一输入和时间范围，并记录通道、版本和增益处理；不同硬件采集的录音属于“竞品整机”对比，不能把差异全部归因于算法。
4. VPU 生成或重建模型听起来更饱满，不代表生成内容一定正确。没有干净参考时，应记录听感与可观察问题，不能据此宣称恢复正确。

- 分歧只是“同一片段出现两种及以上不同偏好”的描述性提示，用于定位需要一起重听的片段，不是算法优劣结论。
- 隐藏模式在服务端保护候选名称和其他人的未公开意见，但管理员掌握主机与数据库，熟悉素材的人也可能凭音频辨认版本。这不是对组织者也不可知的完整双盲。

### 常见问题与处理

先保留页面报错和任务名称，再按对应情况排查。

1. 打开新 exe 仍显示旧版本：关闭浏览器不会停止旧服务。先退出旧程序，再以相同 --data 目录启动新 exe；顶部“服务信息”显示服务版本、页面版本和数据编号，管理员还可查看实际数据目录。新程序遇到端口占用会停止并提示。
2. 角色或分配任务没有更新：在线页面每 5 秒同步，切回网页或点“同步”也会更新；隐藏的后台页面切回后更新。请确认管理员与同事连接同一服务、数据编号相同，任务已经发布并选中了该账号。旧版本页面需先重新加载。同步不会清空未提交标注或选区。
3. 看不到任务：评测者只能看到已发布并分配给自己的任务。请组织者确认发布和成员选择；任务也可能已移入回收站。进行中的任务可由管理员或任务负责人在“参与人员”中增补成员。
4. 没有“新建评测”或上传按钮：请管理员在“团队成员”中将账号设为组织者，在线网页会在约 5 秒内同步，也可点击顶部“同步”。组织者只能管理自己创建的任务；已发布任务不能继续上传。
5. 网页打不开：确认服务主机开机、未睡眠，启动时使用 --lan，访问正确的主机 IP 和端口。文件共享能访问不代表网页端口已放行；联系管理员检查网络规则。
6. 没有声音：先等候选加载完，点击播放，检查底部音量、系统输出设备、耳机连接与浏览器标签页是否静音。仍异常时记录浏览器和报错并联系组织者。
7. 上传被拒绝：核对 WAV、16 kHz、单通道或 4 通道、0.01–120 秒、每文件最多 32 MB；同一片段的候选采样长度必须一致，所选通道必须存在。不接受 NaN/Inf。
8. 批量匹配缺失：比较版本目录内部完整相对路径，包含大小写和 .wav 扩展名。不要只看文件名；子目录不同会视为不同片段。更正目录后重新选择。
9. “任务已关闭”或“已提交”：关闭后不能继续评分；已提交的评分不能修改，可以写补充评论。任务关闭不会自动代表所有人都已完成。
10. 进度里的“未开始”或只有部分完成：受邀名单来自评测分配，负责人自动拥有访问权限但不自动受邀；只写过评论、没有提交偏好判断也属于未开始。进行中的任务负责人可用“评测进度”查看完成状态，关闭后随结果一起展示。
11. “音频资产完整性检查失败”：停止使用该素材，联系管理员核对备份，不要通过手动替换 assets 文件绕过检查。登录失效时重新登录；密码遗失请管理员重置，本版没有自助重置入口。


### 申请加入与免密登录

没有账号的同事可以凭邀请凭证申请加入；批准后的浏览器免密进入。

1. 打开工作台登录页，点击“申请加入评测”，填写显示名称（必填）、工号或邮箱（可选），以及管理员提供的邀请凭证，提交申请。
2. 提交成功后页面显示申请编号并保持等待状态；页面保持打开时会自动进入工作台，也可以关闭浏览器，批准后重新打开继续等待。
3. 管理员批准并分配任务后，原浏览器自动领取设备凭证并登录；此后刷新页面无需再输入密码。
4. 申请被拒绝或邀请失效时，页面会说明结果；重新申请需要向管理员获取新的有效邀请凭证。
5. 点击“退出登录”会同时撤销本浏览器的免密凭证；下次需要重新登录。

- IP 地址只用于审计与风险提示，不是登录凭证；换浏览器或清空 Cookie 后，请管理员重置密码。
- 申请编号不是登录凭证；请不要分享页面中的领取信息。
- 重复提交同一浏览器的申请只会得到同一条记录，不会重复排队。
